# نظام إدارة أجهزة الاتصالات - مديرية المرور

نظام شامل لإدارة الأجهزة السلكية (الاتصالات المحمولة) وأرشيف الكتب الرسمية للاستلام والتسليم لمديرية المرور في بغداد والمحافظات العراقية (عدا إقليم كردستان).

## المميزات

### إدارة الأجهزة
- أنواع الأجهزة: مكتبي، محمول، عجلة
- حالات الجهاز: يعمل، مستهلك غير معطل، مستهلك معطل
- الشركات: هايتيرا، سيبورا، موتورلا + إمكانية إضافة شركات وموديلات جديدة
- تصنيف حسب المحافظة

### أرشيف الكتب الرسمية
- كتب الاستلام والتسليم
- ربط الكتب بالأجهزة
- تغطية 15 محافظة عراقية (بدون إقليم كردستان)

### إدارة المستخدمين
- ثلاث صلاحيات: مدير النظام، مدير، مشغّل
- تسجيل دخول آمن

## التشغيل

### Backend (FastAPI)

```bash
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### Frontend (React + Vite)

```bash
cd frontend
npm install
npm run dev
```

افتح المتصفح على: http://localhost:5173

### بيانات الدخول الافتراضية
- **المستخدم:** admin
- **كلمة المرور:** admin123

## المحافظات المدعومة
